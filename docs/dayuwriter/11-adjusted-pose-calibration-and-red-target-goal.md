# Camera A 新姿态标定记录与红圈跟随目标

## 目标

最终目标是：用户在纸面工作区新放置一个红色实心圆后，系统实时显示该圆心的
图像像素、D435i 相机三维坐标和相对 P0 的物理 XY 坐标；在已验证的安全条件下，
写字机能够移动到该 XY 位置。

这个目标分为三个不能跳过的阶段：

1. 实时感知：识别一个红色目标，显示像素、深度、相机 XYZ。
2. 平面定位：在相机固定、纸面固定、P0 固定时，将目标像素映射为经验证的
   P0-XY（mm）。
3. 受限运动：先由人确认单个稳定目标，再执行一次有工作区边界的 XY 移动；
   连续跟随属于后续阶段，不能在平面精度和单次移动均验证前启用。

`camera_xyz_m` 不是写字机坐标，绝不能直接发送给 GRBL。

## 已完成的软件修正

当前斜视画面中，纸面上的圆形红点投影为约 `14 x 4 px` 的椭圆，面积约 `48 px`，
长宽比约 `3.5`。第一版近圆形筛选要求面积至少 `100 px`、长宽比不超过 `1.5`，
所以错误地返回 `no_target`。

现在的筛选规则是：

- 最小红色连通域面积：`40 px`。
- 最大长宽比：`4.0`，以接受斜视纸面上的透视椭圆。
- 仍要求高饱和红色、填充率至少 `0.55`，并选择最大合格候选。

这只改变视觉显示端，没有串口导入、没有 COM 端口访问、没有 GRBL 命令。
相应提交为 `5f48292` 和 `dd7ba2d`；当前非 GUI 回归结果为 `110 passed`。

## 新姿态平面标定

要恢复物理 XY 显示，需要用相同红色实心圆在同一张纸面采集以下点：

| 用途 | 纸面物理坐标（mm） | 状态 |
| --- | --- | --- |
| 拟合 | `P0 = (0, 0)` | 已采集 |
| 拟合 | `(60, 0)` | 待采集 |
| 拟合 | `(60, 60)` | 待采集 |
| 拟合 | `(0, 60)` | 待采集 |
| 保留验证 | `(30, 30)` | 待采集 |

每次只让画面中保留一个合格的大红点。相机、纸张和 P0 均不得移动；如果原 P0
红点仍在画面，临时用非红色薄纸覆盖它，再将同一个红色标记放到下一坐标。
完成四个拟合点后，以独立的 `(30, 30)` 点报告平均误差和最大误差。只有该验证
通过，页面才能从 `mapping_state: unavailable` 改为显示新的 `machine_xy_mm`。

该四点方形只验证其覆盖区域，不能证明整张纸或完整机械行程的精度。若最终目标
覆盖更大工作区，需要在更大范围重新设计标定点并增加保留验证点。

## 红圈移动与跟随的实现边界

完成新姿态标定后，先实现“单个稳定红圈 -> 人工确认 -> 单次 XY 移动”。它应满足：

1. 仅接受标定区域内的一个红圈，连续多帧像素和预测 XY 稳定后才显示候选坐标。
2. 页面同时显示目标 P0-XY、标定误差、工作区检查结果和 `motion_permission`。
3. 用户确认后，控制程序从物理 P0 的持久 GRBL 会话执行一次有边界的 XY 移动。
4. 必须等待最终 `Idle` 并由人观察实际运动；`ok` 仅表示 GRBL 接受命令。
5. 初始版本不自动 Z 轴，不做无人值守连续跟随。

“红圈跟随”是上述单次移动验证后的独立阶段。安全的跟随版本应在新目标稳定后
更新候选 XY、限制最大位移和更新频率、在目标丢失或超出标定/工作区时停止，且保留
紧急断开 12 V 的人工安全措施。由于这台写字机是开环系统，视觉读数和控制器显示的
坐标都不能替代真实的编码器反馈。
