# 01 硬件恢复与接线

## 1. 设备组成

当前写字机的主要控制硬件：

- Arduino UNO 兼容板，USB 转串口芯片 CH340；
- 红色 CNC Shield V3 扩展板；
- 3 个 A4988 步进电机驱动模块；
- X/Y 平面机构使用两个 42 步进电机；
- Z 轴使用一个 42 步进电机和丝杆；
- 12 V 适配器为电机驱动供电；
- USB 同时承担串口通信和 Arduino 逻辑供电。

## 2. 正确供电结构

必须同时存在两条链路：

```text
电脑 USB
  -> CH340
  -> Arduino UNO
  -> GRBL 通信和逻辑控制

12 V 适配器
  -> DC 转红黑线
  -> CNC V3 的 12-36V 蓝色端子
  -> A4988 VMOT
  -> 步进电机
```

蓝色 Arduino 板上的红色指示灯亮，只能证明逻辑电源存在，不能证明 A4988 和电机获得了 12 V。

本次恢复中，GRBL 接受运动命令但电机无声无动作。重新压紧 CNC V3 的 12 V 电源端子后，电机恢复运动。因此端子接触是本次故障的实际关键点。

## 3. 电源安全规则

- 通电时不要拔插步进电机线。
- 通电时不要拔插或翻转 A4988。
- 不要在没有测量基准的情况下旋转 A4988 电流电位器。
- 调整红黑电源线、端子或驱动模块前，先断开 12 V。
- USB 急停、`Ctrl-X` 或 GRBL 软复位都不等价于切断电机电源。
- 实验时保证可以迅速断开 12 V。

## 4. Windows 当前设备身份

USB 插入后实测：

```text
设备名称：USB-SERIAL CH340 (COM3)
VID:PID：1A86:7523
设备状态：OK
Windows 问题码：CM_PROB_NONE
```

驱动信息：

```text
提供者：wch.cn
版本：3.9.2024.9
日期：2024-09-16
签名：Microsoft Windows Hardware Compatibility Publisher
```

结论：当前电脑不需要重复安装 CH340 驱动。历史记录中的 `COM11` 不能用于当前电脑。

## 5. 当前 GRBL 身份

只读查询得到：

```text
Grbl 1.1f kvenjoy.com ['$' for help]
[VER:1.1f kvenjoy.com.20170131:]
[OPT:VCD0,15,128]
```

关键参数：

```text
$3=4
$20=0
$21=0
$22=0
$100=80.000
$101=80.000
$102=100.000
$110=2000.000
$111=2000.000
$112=8000.000
$130=200.000
$131=200.000
$132=200.000
```

解释：

- `$20=0`：软限位关闭；
- `$21=0`：硬限位关闭；
- `$22=0`：自动回零关闭；
- `$3=4`：当前 Z 方向反相，现场表现为 `Z+` 向下；
- `$130/$131/$132` 不能当作实测机械范围，因为软限位和回零均未启用。

## 6. 当前未解决的硬件状态

状态报告持续包含：

```text
Pn:P
```

在 GRBL 1.1 状态报告中，`P` 表示探针输入处于有效状态。它没有阻止本次 XY/Z 点动，但原因尚未确认。后续如果使用探针、触碰检测或自动 Z 标定，必须先解决这一状态。
