# DayuWriter 几何变化后的重标定与运行手册

## 0. 先判断改变了哪一种几何关系

本系统同时存在四个不同的参考关系：机械 P0、A4 参考板到写字机的纸面关系、相机到参考板的当前视角，以及红方块中心到视觉坐标的本次残余偏移。它们不能互相代替。

```text
笔尖 / 机械 P0  <->  A4 参考板的 P0、X+30、Y+30
                                  ^
                                  |
                  D435i 当前图像中的六个 ArUco 标记
                                  ^
                                  |
                         红方块在同一纸面
```

相机每次启动时会从六个标记恢复**当前相机视角到纸面**的映射。因此只移动相机不必复制旧像素位置或人工重采一批像素点。但如果纸板相对写字机 P0 的位置变了，登记文件不再代表真实纸面，必须重新登记和验证。

## 1. 变化决策表

| 发生的变化 | 人工让笔尖回 P0 | 重新检查/登记 A4 板 | 新建 dashboard 并等待 `ready` | 重新读红方块 P0 基线 | 允许直接运动？ |
| --- | --- | --- | --- | --- | --- |
| 只移动红方块 | 否，前提是笔尖和机器未动 | 否 | 否 | 否 | 仅持续会话已正确武装时 |
| 仅重启 dashboard 或重插 D435i USB | 若写字机未断电、未推、未异常，可保留；否则是 | 否 | 是 | 是 | 否，先预览和小位移验证 |
| D435i 改变高度、角度或支架位置 | 若写字机状态可信可不必；不可信则是 | 否，只要板/纸/P0 没动 | 是 | 是 | 否，先通过质量闸门和小位移验证 |
| A4 板、纸、背板、P0 十字的相对位置/高度/倾角改变 | 是 | 是 | 是 | 是 | 否 |
| 写字机整体搬运、皮带/丝杆/电机线被动过 | 是 | 通常是，并需复测方向/尺度 | 是 | 是 | 否 |
| 12 V 断开、GRBL 重置、USB 重插、手推笔架、碰撞、疑似丢步 | 是 | 板若未动则否 | 视相机是否重启而定 | 是 | 否，先 5 mm 机械复验 |
| 换到 D435i B 或另一台同型号相机 | 是 | 是 | 是 | 是 | 否，A 的相机注册/验证不得照搬 |
| 红方块高出纸面、目标倾斜、需要接触或抓取 | 不适用 | 平面参考板不足 | 不适用 | 不适用 | 否，需要独立三维标定与 Z 安全设计 |

“允许直接运动”栏大多为“否”不是额外拖延。当前没有编码器或已验证自动回零，任何破坏机械位置或平面关系的事件都会使保存的数值失去物理依据。

## 2. 只移动相机时的最快恢复流程

适用条件：仍是同一台 D435i A、同一张已固定且实测尺寸正确的 A4 参考板，板/纸/背板相对写字机 P0 没有移动、弯曲或翘起。

1. 固定相机，使六个标记都清晰入镜。尽量俯视但不要求完全垂直；笔尖、P0 与整个计划工作区需要可见，且无强反光。
2. 关闭 RealSense Viewer 和旧 dashboard。以第 24 号手册第 2 节命令启动一个新 dashboard。
3. 等待 `ready`，确认六 ID 和误差门槛：平均 `<= 1.5 mm`、最大 `<= 3.0 mm`。没通过就调相机、光照或遮挡，不能放宽阈值强行使用。
4. 如写字机经历断电、重启、手推或未知状态，人工将笔尖准确对准 P0；否则也建议目视复核 P0。
5. 把红方块中心放到 P0，从 `state.json` 读取本次浮点 `baselineX/baselineY`。
6. 先运行无串口的预览，检查目标方向；再进行一次实际 `5 mm` XY 复验。验证通过前，不启动连续跟随或 Z 下落。

与手工四点/六点像素标定不同，这个流程的相机姿态变化不会自动使纸面映射过期，因为六标记在当前图像中重新被定位。它不能弥补纸板本身移动、印刷变形或目标离开纸面的情况。

## 3. 参考板、纸面或 P0 改变时的完整重登记

### 3.1 固定并检查打印件

1. 使用 `docs/dayuwriter/reference-board/a4-aruco-v3-300dpi.png`，A4 横向、`100%` 实际尺寸打印；禁止“适应页面”。
2. 量纸上的 `100 mm` 标尺。实测只在 `99--101 mm` 内才可接受。过去一次缩放打印实际只有约 `95 mm`，该纸不能作为几何基准。
3. 将参考板固定在平整、刚性的背板上。红方块工作面必须与参考板同一纸面，不能一个压在纸上、另一个放在悬空台面上。
4. 让六个标记保持干净、平整、无遮挡；不要把红方块、笔架或固定胶带压到黑白方块上。

### 3.2 先用机械事实登记纸面坐标

此阶段仅做小范围受监督机械操作，不启动视觉跟随：

1. 12 V 断开时连接写字机 USB，重新查询实际 `USB-SERIAL CH340 (COMx)`。
2. 机械检查通过后接通 12 V，笔尖悬空并人工对准印刷 P0。
3. 做一次受限 `X+30 mm`；笔尖应对准板上的 `X+30` 十字。人工回 P0。
4. 做一次受限 `Y+30 mm`；笔尖应对准板上的 `Y+30` 十字。人工回 P0。
5. 任一步不对时，先检查板方向、P0 定义、机械轴方向和实际步距；不得仅在网页中更改符号来掩盖错误。

已实测的机械约定是 `X+` 向右、`Y+` 向前、`Z+` 向下。参考板印刷应令 X+ 向右、Y+ 向上，使板面的第一象限与机械正方向一致；浏览器像素 Y 向下不改变该物理约定。

### 3.3 使用网页写入新的人工登记记录

以 `--aruco-reference-board` 启动 dashboard，打开 <http://127.0.0.1:8765/>。在网页的 “Reference board registration” 区域：

1. 只有在 P0、X+30、Y+30 三个机械检查和板固定都完成后，勾选确认框。
2. 点击 `Register board`。
3. 确认页面没有错误，登记文件 `docs/dayuwriter/calibration/camera-a-a4-aruco-registration.json` 被更新。

这个按钮只写入“操作者已确认几何关系”的参考板记录，不能发送 G-code、移动电机或定义 GRBL 原点。它同样不能替代第 3.2 节的三次实际检查。

### 3.4 视觉验收与第一次运行

1. 保持相机、参考板与纸面静止，等待 dashboard 收集参考帧并变为 `ready`。
2. 确认六个 ID 全见、平均和最大保留误差分别不超过 `1.5 / 3.0 mm`。
3. 红方块中心置 P0，读取本次视觉基线。
4. 把方块放到一个已用尺量过的小偏移点，运行预览。预测方向和量级正确后，只做一次小距离 XY。
5. 至少选择一个没有参与板三点机械对齐的纸面位置再次验证。不要用参与拟合或登记的点宣布整个工作区精度。

目前质量闸门约束的是参考板点的图像-纸面一致性，不是整个机械行程的绝对误差地图。若日后需要全行程精度主张，应在工作区网格上使用独立尺量点记录平均、最大误差与重复性。

## 4. 何时必须停止，而不是“快速重标定”

下列情形不能由平面 ArUco 流程解决：

- 目标高于/低于参考纸面，或目标倾斜、移动、遮挡纸面；平面单应性不能给出可靠的写字机 Z。
- 笔尖实际碰到纸、底板或物体；先断 12 V 并检查机械，不要用相机坐标继续补偿。
- `Pn:P` 持续有效；这提示探针输入状态异常或至少未被解释，不能做探针 Z 标定。
- 相机无法稳定获得深度、标记不全或验收误差超过阈值；先处理 USB、独占、光照、安装或纸张，不能降低门槛。
- 不再使用红色平面方块，而要识别杂草或抓取物。那是新的感知、相机外参、目标高度、碰撞与执行器问题，必须另行验证。

## 5. 可重复的记录模板

每次重标定后，在 `docs/dayuwriter/baseline/` 新建一个带日期的记录，至少写入：

```text
相机序列号、USB 类型、dashboard 启动命令
参考板文件/打印实测 100 mm 尺寸
P0 / X+30 / Y+30 的现场观察
六个可见 ID、mean_error_mm、max_error_mm
本次 P0 视觉 baselineX/baselineY
一个独立验证点：尺量坐标、页面坐标、误差
实际 COMx、5 mm 运动、最终 Idle、人工观察
是否有相机/板/纸/机械变化以及对应处置
```

这份记录的作用是区分“本次部署通过”与“过去某次部署曾通过”。没有新的现场证据时，不要把旧成功记录升级为当前成功。
