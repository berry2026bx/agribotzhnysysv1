# DayuWriter 简明标定操作

这份手册只说明不使用 Codex 时必须亲手完成的标定动作。桌面启动器负责启动相机、网页和自动跟随；它不能替代纸面、笔尖和机械位置的物理确认。

## 情形一：只有相机角度或高度改变

1. 双击 `scripts\start_dayuwriter_gui.cmd`。
2. 点击“启动可视化”，浏览器会打开页面。
3. 调整相机，直到页面的六个 ArUco 方块都完整可见，状态为 `ready`，并且平均误差不超过 `1.5 mm`、最大误差不超过 `3.0 mm`。
4. 将笔尖和红方块中心同时对准 P0。
5. 首次更换机位后，先把红方块放到一个已知小偏移处，确认页面坐标方向正确；再用写字机的 5 mm 小位移复验。

参考板、纸面和 P0 没有移动时，不点击网页中的 `Register board`。桌面启动器在“从 P0 启动自动跟随”时会自动读取当前 P0 视觉基线。

## 情形二：纸板、P0、纸面或写字机相对位置改变

1. 用 A4 横向、100% 实际尺寸打印参考板；量 `100 mm` 标尺，只有 `99--101 mm` 才继续。
2. 把参考板固定在平整硬背板上，红方块也必须放在同一纸面。
3. 在桌面启动器勾选现场确认，点击 `X+30`，确认笔尖落在 X+30 十字；再点击 `X-30` 回到 P0。
4. 点击 `Y+30`，确认笔尖落在 Y+30 十字；再点击 `Y-30` 回到 P0。
5. 点击桌面启动器的“启动可视化”，在浏览器页面勾选确认并点击 `Register board`。
6. 等六个标记和误差门槛通过；红方块回 P0；先做一个小距离视觉验证，再启动自动跟随。

## 情形三：更换 D435i

把它视为情形二。不能把旧相机的标定、P0 基线或误差记录当作新相机已经通过标定的证据。

## 必须停止的情况

相机/参考板状态不是 `ready`、六个标记不全、误差超限、红方块离开纸面、笔尖碰到物体、发生断电/手推/碰撞/丢步、或串口异常时，停止自动跟随。机械风险先断 12 V；恢复后重新对准 P0。
