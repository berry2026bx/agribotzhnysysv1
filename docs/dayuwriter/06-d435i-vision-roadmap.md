# 06 RealSense D435i 视觉改造路线

## 1. 总目标

最终系统需要完成：

```text
相机采集
-> 目标检测或分割
-> 获得目标像素
-> 获得深度
-> 计算相机三维坐标
-> 转换为 P0 机械坐标
-> 检查工作范围
-> 移动到目标 XY
-> 在安全条件下处理 Z
```

当前机械控制已经能够接收安全的 XY P0 坐标，但视觉部分尚未实现。

## 2. 第一阶段：设备和数据流

1. 将 D435i 直接连接 USB 3.x 接口；
2. 在 Windows 设备管理器和 RealSense Viewer 中确认设备；
3. 安装与当前 Python 版本兼容的 `pyrealsense2`；
4. 枚举设备名称、序列号和 USB 类型；
5. 读取彩色帧和深度帧；
6. 将深度对齐到彩色图；
7. 保存一组原始 RGB、深度和元数据作为基线。

此阶段不发送任何写字机运动。

## 3. 第二阶段：像素到相机坐标

对于彩色图中的像素 `(u,v)`：

1. 从对齐后的深度图读取深度 `d`；
2. 使用 RealSense 内参反投影；
3. 得到相机坐标系点：

```text
Pc = [Xc, Yc, Zc, 1]^T
```

必须处理：

- 深度为 0；
- 反光和空洞；
- 深度噪声；
- 彩色与深度对齐；
- 多帧中值或空间滤波；
- 工作平面以外的目标。

## 4. 第三阶段：相机到机器坐标

需要估计外参矩阵：

```text
Pm = T_machine_camera * Pc
```

其中 `Pm` 是以 P0 为基准的机械坐标。

### 固定上方相机

相机固定观察整个工作区，外参在相机不移动时保持不变。可在工作平面放置多个标志点，并让写字机移动到对应 P0 坐标，建立像素/三维点与机械坐标配对。

优点：标定和验证更简单，适合第一版。

### 安装在移动滑台

相机随 XY 机构移动，相机位姿与机器位置共同变化，需要手眼标定或明确的机械安装变换，还要处理线缆拖链和视野变化。

优点：可近距离观察局部目标；缺点是标定和运动规划更复杂。

第一版推荐固定上方相机。

## 5. 外参标定数据要求

- 至少覆盖工作区多个位置，而不是只测中心；
- 标定点应覆盖四角和中间；
- 训练点和验证点分开；
- 记录每个点的像素、深度、相机坐标和 P0 机械坐标；
- 报告平均误差、最大误差和边缘区域误差；
- 误差未达到任务要求前，只显示预测坐标，不驱动机器。

如果所有目标都位于一个固定平面，可先使用平面单应性作为 XY 基线；需要真实高度和 Z 定位时，必须使用深度和三维外参。

## 6. 目标检测接入

目标检测模型只能提供目标类别和图像位置，不能自动提供可靠机械坐标。推荐处理顺序：

```text
检测框或分割掩膜
-> 选择目标代表像素
-> 深度有效性检查
-> 相机三维坐标
-> 机器坐标
-> 安全范围和置信度检查
-> 人工确认
-> XY 移动
```

杂草任务更适合使用分割掩膜或目标底部/质心规则，而不是无条件使用检测框中心。

## 7. 运动接入分级

### Level 1：只显示

显示像素、深度、相机坐标和预测 P0 坐标，不移动机器。

### Level 2：人工确认后移动

用户确认一个目标后调用受限 `goto`。

### Level 3：自动 XY

只在标定误差、目标置信度、深度有效性和安全范围全部通过时自动移动 XY。

### Level 4：自动 XYZ

只有完成 Z 边界、工具高度、碰撞检测和物理急停后才能启用。

## 8. D435i 接入前的剩余机械事项

- 进行更大范围、多循环的 XY 重复定位测试；
- 测量反向间隙；
- 解决或解释 `Pn:P`；
- 固定 12 V 电源线和相机线；
- 确定相机固定方式；
- 建立可重复恢复 P0 的方案；
- 标定 Z_SAFE 和工具工作高度。

## 9. 下一次实验入口

找到 D435i 后：

1. 写字机保持 P0；
2. 暂时关闭 12 V；
3. D435i 连接 USB 3.x；
4. 只做 Windows 枚举和图像读取；
5. 不安装检测模型，不发送运动。
