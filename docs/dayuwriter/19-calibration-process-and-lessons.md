# DayuWriter 标定过程与经验

本文是本项目的标定档案，不是通用原理课，也不是即时操作清单。它按已经发生的实验过程记录：每种标定解决什么问题、接受或淘汰的依据是什么、何时必须重新做。所有长度单位均为 `mm`；相机深度原始单位为 `m`。

## 1. 先区分四类标定

| 类别 | 回答的问题 | 当前性质 |
| --- | --- | --- |
| 机械尺度标定 | `jog X/Y/Z 20` 是否约等于实际 20 mm | 已做基础实测，未修改 `$100/$101/$102` |
| 人工 P0 标定 | 写字机的 `(0, 0)` 在纸面哪里 | 每次物理状态失效后必须人工恢复 |
| 相机平面标定 | RGB 像素或红方块如何换算到纸面 P0-XY | 已从手工点拟合升级为 A4 ArUco 参考板 |
| 目标动作验证 | 显示的视觉坐标是否能产生正确的受限移动 | 已完成一次受监督的 XY 加 1 mm Z 下落演示 |

它们不能互相替代。例如，GRBL 显示 `MPos` 不会自动证明相机坐标正确；相机在画面中显示 `(0,0)` 也不会自动证明笔尖处于物理 P0。

## 2. 机械尺度、轴方向和 P0

### 2.1 机械尺度复查

恢复阶段以小幅相对 Jog 起步，现场测量确认：X、Y 指令 `20 mm` 的实际位移约为 `20 mm`；Z 累计 `10 mm` 的下移约为 `10 mm`。因此没有为了“看起来更准”而改写 GRBL 的 `$100/$101/$102`。历史现场记录保留了 `$100=80`、`$101=80`、`$102=100` 的工作配置。

已现场确认的正方向是：

```text
X+：向右
Y+：向前
Z+：向下
```

方向不是由相机图像的上下左右推断，而是由实机小幅测试确定。图纸、屏幕像素坐标和机械正方向必须分别标注，不能因为 SVG 或图像的 Y 轴向下就把机械 Y+ 反向。

### 2.2 人工 P0

P0 是纸面上的人工物理基准点。建立方法是：笔尖悬空或可安全对准标记，人工把笔尖精确放到 P0，再开始使用以 P0 为解释基准的控制和视觉数据。

当前系统没有编码器、可靠的自动回零链路或已验证的限位回零。因此以下事件都会使软件保存的机械位置失去物理可信度：断开 12 V、重插 USB、GRBL 复位、手推笔架、疑似丢步、串口异常或机械碰撞。发生任意一项时，必须停止自动序列，重新把笔尖物理对准 P0；不能以 `MPos` 取代这个动作。

根据已测机械余量并保留 10 mm 余量，Python 控制层曾使用：

```text
X: -190 到 +190 mm
Y:  -90 到 +140 mm
```

这是当时 P0、机构和纸面条件下的受限软件范围，不是设备铭牌行程。Z 轴没有可验证的软件工作边界；因此任何 Z 动作都必须独立确认笔尖悬空和剩余空间。

## 3. 早期相机平面标定：哪些结果被淘汰

### 3.1 手工点拟合的价值和局限

最早的相机 A 平面标定以笔尖处于已知 P0-XY 位置时的 RGB 像素为样本，拟合相机像素到纸面 XY 的二维映射。这个阶段的目的只是证明“坐标变换链条存在”，而不是立即授权运动。

相机 A 为 Intel RealSense D435i，序列号 `231122070403`。RGB-D 采集使用深度向彩色对齐；深度尺度、内参、相机三维点和纸面 XY 仍属于不同层次的数据。相机 XYZ 不能直接当作写字机 XYZ。

### 3.2 被否决的结果

两个早期结果被明确淘汰：

- 首个正方形映射的保留验证误差为 `28.053 mm`，不具备使用价值。
- 后续 v2 记录在恢复后重新采集 P0 时发生约 `75 px` 的像素几何漂移，说明旧相机姿态或纸面几何已变化，旧映射不再描述现场。

这两次失败说明：即使拟合点本身看上去误差小，也不能只检查参与拟合的点。必须留出未参与拟合的验证点，并把“相机、纸面或参考物发生移动”视为标定失效事件。

### 3.3 v3 手工基准结果

在稳定姿态下，以 `P0`、`X30Y0`、`X30Y30`、`X0Y30` 描述 `0-30 mm` 区域，留出 `(15,15)` 和 `(10,20)` 作为独立验证点。v3 的保留验证为：

| 物理点 | 预测值 | 误差 |
| --- | --- | --- |
| `(15,15)` | `(15.195,14.556)` | `0.485 mm` |
| `(10,20)` | `(9.747,20.860)` | `0.896 mm` |

平均误差为 `0.691 mm`，最大误差为 `0.896 mm`。该结果只覆盖当时的 `0-30 mm` 小区域，且当时保持 `display_only`；它不能外推到整个工作区，也不能在改变安装姿态后继续使用。

## 4. A4 六 ArUco 标记参考板

### 4.1 为什么改用参考板

手工逐点标定要求相机、纸张和笔架姿态在过程内保持不变，重新部署成本高。为降低“相机一动就从头找像素”的成本，项目制作了 `a4-aruco-v3` 参考板：六个 `DICT_4X4_50` ArUco 标记与纸面 P0-XY 位置建立已知关系。

参考板的作用是让软件在每次相机启动时重新识别纸面几何，而不是永久保存某一帧图像。它仍不是机械回零装置，也不替代 P0 的物理定义。

### 4.2 打印、安装和登记

1. 使用 [a4-aruco-v3-300dpi.png](reference-board/a4-aruco-v3-300dpi.png) 或 [a4-aruco-v3.svg](reference-board/a4-aruco-v3.svg)，A4 横向、`100%` 实际尺寸打印，禁止“适应页面”。
2. 用尺测量印刷的 `100 mm` 标尺；仅在实测 `99-101 mm` 时使用。此前出现过缩放打印，`100 mm` 标尺仅约 `95 mm`，该板不能作为几何基准。
3. 将纸固定在刚性平整背板上，使它与红色目标所在平面一致，不能翘曲、悬空或独立滑动。
4. 让笔尖对准印刷 P0；从 P0 做受限 `X+30 mm` 和 `Y+30 mm` 检查，笔尖必须分别落到板上对应十字。只有三点一致后才固定板。
5. 在界面中登记参考板。这一操作记录物理确认，不会发送 G-code、定义 GRBL 原点或移动电机。

印刷 X+ 向右、Y+ 向上必须和已验证的写字机 X+/Y+ 一致。参考板上的屏幕像素方向不是机械方向。

### 4.3 每次运行的质量闸门

当前高分辨率运行使用彩色 `1280x720 rgb8@30`、深度 `640x480 z16@30`，并将深度对齐到彩色。启动时先丢弃 `90` 帧，让曝光稳定；随后收集 `12` 帧完整的六标记观测。

只有满足下面条件，页面才报告 `ready` 并显示红目标的纸面 XY：

```text
六个 ID 均可见
保留标记验证：平均误差 <= 1.5 mm
保留标记验证：最大误差 <= 3.0 mm
红目标几何中心投影在参考板定义的纸面区域内
```

`ready` 允许显示坐标，不等于“自动运动已获许可”。标记丢失、误差超标或相机帧异常时，坐标必须被撤销而不是沿用旧矩阵。

### 4.4 现场验证结果

在一次六标记完整入镜的高分辨率会话中，保留标记的平均误差为 `1.345 mm`、最大误差为 `2.348 mm`，通过显示质量门槛。后续固定状态下的 P0 红方块检查得到平均 `1.472 mm`、最大 `2.175 mm` 的保留标记误差；将约 `10 x 10 mm` 非反光红方块的几何中心置于 P0，显示约 `X=2.03 mm, Y=0.08 mm`。

这个约 `2 mm` 的 X 偏差没有被伪装为“零误差”。它可能包含纸张定位、红色分割质心、参考板安装和映射误差；在当前显示标定误差量级内，仅可说明红方块在 P0 附近。

## 5. 红方块、视觉基线和第一次动作验证

红方块是高对比度、固定尺寸、与纸面共面的演示目标，不是杂草检测模型。实时页面输出红色候选框、目标中心和 P0-XY；它没有串口权限，页面刷新或相机异常不会直接运动写字机。

为了将页面显示转成一次可审查的相对 Jog，控制程序保存“红方块放在物理 P0 时”的视觉基线。现场一份可用基线为：

```text
视觉 P0 基线: X=1.927 mm, Y=0.169 mm
```

这不是新的机械原点；它只是消除当时视觉显示残余偏移的参考。基线仅在相机、板、纸面和 P0 关系未改变时有效。

一次完整受监督演示的记录如下：

1. 笔尖物理回到 P0，12 V 已接到 CNC V3，笔尖悬空，XY 全路径和 Z 向下空间均由操作者确认。
2. 页面排除了 A4 外的一块错误红色候选，只保留纸面内的红方块。
3. 新快照的目标为约 `X=14.008, Y=-15.002`，扣除基线后建议相对量为 `X=12.081, Y=-15.171`。
4. 同一条 `COM4` 持久串口会话以 `50 mm/min` 分段发送 X/Y，每段不超过约 `4.027 mm` 或 `3.793 mm`，每段等待 `ok` 和最终 `Idle`。
5. XY 成功后才发送 `Z+1.000 mm`；现场确认笔尖接近红方块中心并向下约 `1 mm`。

该演示证明“纸面内红方块检测 -> 平面 XY 显示 -> 有界相对运动 -> 小幅 Z 下落”可在受监督条件下工作。它不证明毫米级绝对精度、目标抓取、杂草识别、整机无限工作范围或无人值守安全。

## 6. 标定何时仍有效，何时必须重做

| 变化 | 是否必须重新做 P0/板登记 | 是否必须重新通过页面质量闸门 | 结论 |
| --- | --- | --- | --- |
| 只更换电脑、板与机器关系未变 | 否 | 是 | 新电脑要重新识别设备并启动新的相机会话 |
| 相机 A 换位置或角度，参考板仍刚性固定 | 否 | 是 | 参考板设计用于恢复相机姿态；必须六标记完整且误差合格 |
| 相机断电、USB 重插或程序重启 | 否 | 是 | 重新打开页面、重新收集有效帧；机械 P0 是否有效另行判断 |
| 纸、板、背板的高度、平整度、倾角或相对 P0 变化 | 是 | 是 | 纸面映射几何改变，必须重新机械对准并登记 |
| P0 改点、笔架被手推、断电或疑似丢步 | 机械 P0 必须恢复；板相对 P0 改变时也需登记 | 是 | 开环 MPos 不能修复物理基准 |
| 换成 D435i B | 是 | 是 | 代码可复用，内参、深度和安装外参不能复用 |

## 7. 可复用的标定经验

- **先测打印尺寸，再用参考板。** 几何标尺错 5%，后续软件再复杂也无法补救。
- **拟合点和验收点分开。** 只报告训练点误差会掩盖过拟合或板安装错误。
- **用质量闸门替代“相信旧结果”。** 标记完整、稳定帧和保留误差必须持续可见。
- **把目标限制在参考平面内。** 纸面单应映射不能合法外推到笔架、导轨、悬空目标或纸外红物体。
- **每个坐标带名称和单位。** 相机 XYZ（米）、RGB 像素、纸面 P0-XY（毫米）、GRBL MPos（开环内部值）不可混写。
- **将标定与运动解耦。** 页面负责测量与显示；独立控制器在显式参数、人工前提和范围检查完成后才可能打开串口。
- **Z 是另一项标定任务。** 当前只做过安全条件下的固定 `1 mm` 下落；没有完成“由深度估计目标高度并自动接触”的三维标定。
