# Git Repository Rules

本文件是团队 GitHub 仓库的基本使用规则。所有成员上传文件前应先阅读。

## 1. 仓库用途

本仓库用于保存项目学习、实验、代码、文档、图纸、数据说明和测试记录。

所有重要过程资料都应沉淀到仓库中，不能只保存在个人电脑、U 盘或聊天群里。

## 2. 基本要求

- 文件放到对应目录。
- 文件名要清楚。
- 每次提交都要写清楚说明。
- 不上传隐私、密码、密钥和未经允许公开的内容。
- 大文件不要直接放进仓库。

## 3. 提交说明格式

格式：

```text
类型: 具体修改内容
```

示例：

```text
docs: add weekly report
comm: add modbus notes
plc: add io map template
ros2: add topic demo notes
test: add plc test record
```

## 4. 常用提交类型

| 类型 | 含义 |
| --- | --- |
| `docs` | 文档、笔记、周报、说明 |
| `comm` | 通讯协议资料 |
| `plc` | PLC 资料 |
| `ros2` | ROS2 资料或代码 |
| `firmware` | 下位机代码 |
| `cad` | CAD 和结构设计 |
| `sim` | 仿真资料 |
| `data` | 数据和标注说明 |
| `test` | 测试记录 |
| `fix` | 修正错误 |

## 5. 禁止上传

- 密码、验证码、Token、SSH 私钥
- 手机号、身份证号、家庭地址等个人隐私
- 服务器密码、数据库密码、设备公网 IP
- 未经允许公开的专利核心细节
- 大量原始视频、大量图片或超大数据集
- 未经授权的第三方资料

## 6. 周检查标准

每周检查：

1. 是否有提交记录。
2. 文件是否放在正确目录。
3. 文件内容是否能支撑学习、实验或成果整理。
4. 测试记录是否包含时间、设备、步骤、结果和问题。
5. 是否存在隐私或敏感内容。
